# Percentage — Day 2 Short Revision Notes

## DSSSB 2026 | Percentage Foundation — Day 2

# 1. Percentage ↔ Fraction Basic Rule

### Percentage → Fraction
Percentage ko **100 se divide** karo.

Example:
- 10% = 10/100 = 1/10
- 25% = 25/100 = 1/4
- 37.5% = 37.5/100 = 3/8

### Fraction → Percentage
Fraction ko **100 se multiply** karo.

Example:
- 1/2 = 50%
- 3/8 = 37.5%
- 5/4 = 125%

---

# 2. Original Number vs Final Number

Ye Day 2 ka important concept hai.

Agar kisi number mein `p%` add kiya gaya:

> Final Number = Original Number × (100 + p)/100

### Example

Kisi number mein 37.5% add karne par 1320 milta hai.

37.5% = 3/8

Therefore:

Original + 3/8 Original
= 11/8 Original

So,

11/8 × Original = 1320

Original = 1320 × 8/11

= **960**

### Shortcut

Agar:

> p% increase ke baad value = Final

To:

> Original = Final × 100/(100+p)

---

# 3. Percentage Decrease ke Baad Original Number

Agar kisi number ko `p%` decrease karne ke baad final value di ho:

> Final = Original × (100-p)/100

Therefore:

> Original = Final × 100/(100-p)

### Example

Agar 20% decrease ke baad value 800 hai:

Original = 800 × 100/80

= **1000**

---

# 4. Percentage ko Mixed Fraction mein Convert Karna

Exam mein percentage ko fraction mein convert karna bahut useful hai.

### Important:

37.5% = 3/8

12.5% = 1/8

62.5% = 5/8

87.5% = 7/8

120% = 6/5

137.5% = 11/8

# 5. Original Number Identify Karna

Fraction mein:

> Neeche wala number → Original/Base number

> Upar wala number → Percentage/Result part

Example:

3/8 ka matlab:

- 8 = Original ke parts
- 3 = Percentage result ke parts

Agar 3/8 part = 1320 diya hai:

Original = 1320 × 8/3

---

# 6. Given Fraction of a Number → Another Percentage

Agar kisi number ka ek fractional part diya hai aur doosra percentage poocha hai:

### Example

Kisi number ka 2/5 = 69 hai.

Number ka 40% find karo.

Since:

40% = 2/5

Jo value 2/5 ki hai = **69**

Therefore answer = **69**

### Rule

Agar:

> Given value = a/b of number

Aur question mein:

> a/b ka percentage/value poocha gaya hai

To direct answer mil sakta hai.

---

# 7. Mixed Fraction Percentage

Example:

Kisi number ka 7/9 = 70 hai.

Number ka 44 4/9% find karo.

44 4/9%

= 400/9%

= 4/9

Therefore:

7/9 → 70

4/9 → ?

= 70 × 4/7

= **40**

### Shortcut

Pehle percentage ko fraction mein convert karo.

Phir given fraction ke saath compare karo.

---

# 8. Percentage Error — Wrong Operation

Agar actual operation kuch aur hona tha aur galat operation kiya gaya, to percentage error nikal sakte hain.

### Basic Formula

> Percentage Error =
> (Error / Correct Value) × 100

### Example Idea

Agar correct multiplication/division se value `Correct` aati hai aur wrong operation se `Wrong` value aati hai:

> Error = |Correct - Wrong|

Then:

> Error % = Error/Correct × 100

⚠️ **Denominator generally correct/original result hota hai.**

---

# 9. Wrong Multiplication / Division

Agar kisi quantity ko multiply karna tha:

> × 5/3

Lekin galti se:

> × 3/5

kar diya.

To pehle:

1. Correct value nikalo
2. Wrong value nikalo
3. Difference nikalo
4. Correct value se percentage error nikalo

---

# 10. Multiple Operations mein Sequence Important Hai

Agar question mein operation ka sequence diya hai:

> Multiply → Add → Divide

To isi order mein solve karo.

### Important

Question ke prescribed operations ko unnecessarily rearrange mat karo.

Example:

Original number

→ × 2

→ + 10

→ ÷ 5

To exactly isi sequence ko follow karna hai.

# 11. Comparison of Two Numbers

Ye Day 2 ka **very important pattern** hai.

### Example

A, C se 20% zyada hai.

B, C se 25% zyada hai.

Find:

> B is what % of A?

Assume:

C = 100

Then:

A = 120

B = 125

Therefore:

B as % of A

= 125/120 × 100

= **104.17% approx**

⚠️ Dhyan:

> "B is what % of A?"

aur

> "B is how much % more than A?"

dono alag questions hain.

---

# 12. Percentage More vs Percentage of

### Example

A = 100  
B = 120

### B is what % of A?

120/100 × 100

= **120%**

### B is how much % more than A?

(120-100)/100 × 100

= **20%**

So:

> Percentage OF ≠ Percentage MORE

---

# 13. Two Numbers are Less Than a Third Number

### Example

A third number = 100

First number is 30% less:

A = 70

Second number is 40% less:

B = 60

Question:

> B is what % of A?

= 60/70 × 100

= **85.71% approx**

---

# 14. "Less Than" Questions ka Setup

Agar:

A is 30% less than C

B is 40% less than C

Assume:

C = 100

Then:

A = 70

B = 60

Ab question ke according A aur B ka comparison karo.

# 15. ×99 Shortcut

Exam calculation ke liye:

> Number × 99 = Number × (100 - 1)

### Example

54 × 99

= 54 × 100 - 54

= 5400 - 54

= **5346**

### Another

57 × 99

= 5700 - 57

= **5643**

---

# 16. ×999 Shortcut

> Number × 999 = Number × (1000 - 1)

### Example

587 × 999

= 587000 - 587

= **586413**

### Another

613 × 999

= 613000 - 613

= **612387**
