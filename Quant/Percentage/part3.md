# 1. Percentage का Basic Meaning

**Percentage = Per 100**

\[
x\%=\frac{x}{100}
\]

### Important conversions

| Fraction | Percentage |
|---|---:|
| 1/2 | 50% |
| 1/3 | 33⅓% |
| 1/4 | 25% |
| 1/5 | 20% |
| 1/6 | 16⅔% |
| 1/7 | 14⅖% |
| 1/8 | 12.5% |
| 1/9 | 11⅑% |
| 1/10 | 10% |
| 1/11 | 9 1/11% |
| 1/12 | 8⅓% |
| 1/16 | 6¼% |
| 1/20 | 5% |

### Rule

**Percentage → Fraction**

\[
x\%=\frac{x}{100}
\]

**Fraction → Percentage**

\[
\frac{x}{y}\times100
\]

# 2. Percentage को Fraction में बदलना

### Example

**Q. 37.5% को fraction में बदलो.**

\[
37.5\%=\frac{37.5}{100}
\]

\[
=\frac{3}{8}

37.5% = **3/8**

# 3. Fraction को Percentage में बदलना

### Example

**Q. 3/8 कितने प्रतिशत है?**

\[
\frac38\times100=37.5\%
\]

### Shortcut

Fraction को percentage में बदलने के लिए **100 से multiply** करो.

---

# 4. किसी Number का Percentage निकालना

### Formula

\[
x\% \text{ of } N=\frac{x}{100}\times N
\]

### Example

**Q. 500 का 20% कितना है?**

\[
500\times\frac{20}{100}=100
\]

**Answer = 100**

---

# 5. Percentage Value दी हो, Original Number निकालना

यह lecture का बहुत important pattern है.

### Example

**Q. किसी संख्या का 40% = 120 है। संख्या क्या है?**

40% = 2/5

\[
\frac25 N=120
\]

\[
N=120\times\frac52=300
\]

**Answer = 300**

### Shortcut

अगर:

\[
x\% \text{ of } N=A
\]

तो:

\[
N=A\times\frac{100}{x}
\]

---

# 6. Number में उसका Percentage जोड़ दिया गया

### Example

**Q. किसी संख्या में उसका 25% जोड़ने पर 500 हो जाता है। Original number क्या था?**

Original = 100%

25% add हुआ:

\[
100\%+25\%=125\%
\]

125% = 500

\[
Original=500\times\frac{100}{125}
\]

\[
=400
\]

**Answer = 400**

### Shortcut

Increase by \(x\%\):

\[
New=Original\times\frac{100+x}{100}
\]

---

# 7. Number में उसका Percentage घटा दिया गया

### Example

**Q. किसी संख्या में से 20% घटाने पर 640 बचता है। Original number?**

Remaining:

\[
100\%-20\%=80\%
\]

80% = 640

\[
Original=640\times\frac{100}{80}=800
\]

**Answer = 800**

### Shortcut

Decrease by \(x\%\):

\[
New=Original\times\frac{100-x}{100}
\]

# 9. Mixed Percentage का उपयोग करके Original Number

### Example

**Q. किसी संख्या में उसका 37.5% जोड़ने पर 1100 हो जाता है। Original number?**

37.5% = 3/8

Total:

\[
1+\frac38=\frac{11}{8}
\]

Therefore:

\[
\frac{11}{8}N=1100
\]

\[
N=1100\times\frac8{11}=800
\]

**Answer = 800**

# 10. "A is x% More Than B"

### Example

**Q. A, B से 20% ज्यादा है। यदि B = 100 है, तो A कितना होगा?**

B = 100

20% of 100 = 20

\[
A=100+20=120
\]

**Answer = 120**

# 11. "A is x% Less Than B"

### Example

**Q. A, B से 30% कम है। यदि B = 100 है, तो A कितना होगा?**

\[
A=100-30=70

**Answer = 70**

# 12. दो Numbers Third Number से अलग-अलग Percentage ज्यादा हैं

यह बहुत important pattern है. Lecture में इसे repeatedly emphasize किया गया है.

### Example

**Q. A किसी तीसरी संख्या से 20% ज्यादा है और B उसी तीसरी संख्या से 25% ज्यादा है। B, A का कितने प्रतिशत है?**

Third number = 100

\[
A=120
\]

\[
B=125
\]

अब पूछा है:

**B is what % of A?**

\[
\frac{125}{120}\times100
\]

\[
=104.17\%
\]

**Answer = 104.17%**

### ⚠️ ध्यान रखो

"B, A से कितने % ज्यादा है?"

और

"B, A का कितने % है?"

दो अलग questions हैं.

# 14. "A is x% More Than B" — Reverse Percentage

यह बहुत important trap है.

### Example

**Q. A, B से 25% ज्यादा है। B, A से कितने % कम है?**

मान लो:

\[
B=100
\]

तो:

\[
A=125
\]

Difference:

\[
25
\]

अब decrease किसके ऊपर है?

**A = 125**

\[
\frac{25}{125}\times100=20\%
\]

**Answer = 20%**

### याद रखो

25% increase का reverse decrease **25% नहीं**, बल्कि:

\[
\frac{25}{125}\times100=20\%
\]

# 16. Percentage Difference से दो Numbers निकालना

Sum = 100

Difference = 15

अब:

\[
Big+Small=100
\]

\[
Big-Small=15
\]

Add:

\[
2Big=115
\]

\[
Big=57.5
\]

\[
Small=42.5
\]

Ratio:

\[
57.5:42.5
\]

\[
=115:85
\]

\[
=23:17
\]

**Answer = 23:17**

# 18. किसी Number का Percentage दिया है और दूसरा Percentage पूछना

### Example

**Q. किसी संख्या का 40% = 80 है। उसी संख्या का 25% कितना होगा?**

40% = 80

25% निकालना है.

Ratio:

\[
\frac{25}{40}\times80
\]

\[
=50
\]

**Answer = 50**

### Shortcut

अगर एक percentage का value दिया है:

\[
Required\ Value
=
Given\ Value\times
\frac{Required\%}{Given\%}
\]
