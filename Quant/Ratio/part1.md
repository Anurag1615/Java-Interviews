## 1. अनुपात की बुनियादी बातें

**नियम 1: अनुपात हमेशा एक जैसी इकाई (unit) में लिया जाता है।**

- 6 kg : 8 kg = 3 : 4
- 10 m : 15 km ≠ 2 : 3 ❌
  - 15 km = 15000 m → 10 : 15000 = **1 : 1500** ✔

**नियम 2: a/b = 3/2 का मतलब a = 3 और b = 2 नहीं है।**

- असल में a = 3k, b = 2k (k कोई भी संख्या)
- जैसे 15 : 10 या 12 : 8, सब कटकर 3 : 2 बनते हैं।

**नियम 3: सीधे मान (a = 3, b = 2) तभी रख सकते हो जब हर पद की घात (power) बराबर हो।**

| व्यंजक (a/b = 3/2) | घात | उत्तर |
|---|---|---|
| (a² + b²)/(a² − b²) | दोनों 2 | (9 + 4)/(9 − 4) = **13/5** |
| (a³ + b³)/(a³ − b³) | दोनों 3 | (27 + 8)/(27 − 8) = **35/19** |
| (a³ + b²)/(a³ − b²) | 3 और 2 | **ज्ञात नहीं किया जा सकता** (k बचा रहता है) |

## 2. टाइप 1 – सीधे मान रखकर

**Q1.** स्कूल में 640 छात्र हैं, जिनमें 400 लड़के हैं। लड़कियों : लड़कों का अनुपात?

- लड़कियाँ = 640 − 400 = 240
- 240 : 400 = **3 : 5**

> "लड़कियों : लड़कों" पूछा है, क्रम ध्यान से पढ़ो।

**Q2.** a/b = 3/4 है, तो (5a + 2b)/(7a − 3b) = ?

- a = 3, b = 4 रखो (सबकी घात 1 है)
- (15 + 8)/(21 − 12) = **23/9**

**Q3.** a/b = 5/7 है, तो (6a² − 2b²)/(b² − a²) = ?

- (6 × 25 − 2 × 49)/(49 − 25) = (150 − 98)/24 = 52/24 = **13/6**

## 3. टाइप 2 – योगांतरानुपात (Componendo–Dividendo)

**नियम:** अगर (A + B)/(A − B) = p/q, तो **A/B = (p + q)/(p − q)**
(ऊपर जोड़ो, नीचे घटाओ। Cross-multiply की ज़रूरत नहीं।)

उदाहरण: (3x + 2y)/(3x − 2y) = 4/3 → 3x/2y = 7/1 → x/y = **14/3**

**Q4.** (5x + 3y)/(5x − 3y) = 7/3 है, तो x : y = ?

- 5x/3y = (7 + 3)/(7 − 3) = 10/4
- x/y = 10 × 3 / (4 × 5) = **3 : 2**

**Q5.** (7x + y)/(7x − y) = 7/2 है, तो x : y = ?

- 7x/y = 9/5 → x/y = **9/35**

**Q6.** (x + y)/(x − y) = 7/3 है, तो (x² + y²)/(x² − y²) = ?

- x/y = 10/4 = 5/2
- (25 + 4)/(25 − 4) = **29/21**

## 4. टाइप 3 – a/b = c/d = e/f वाले सवाल

**नियम:** अगर ऊपर और नीचे के गुणांक (coefficients) **एक जैसे** हों, तो उत्तर वही अनुपात होता है जो दिया है। बस पहले जोड़े का अनुपात लो।

**Q7.** a/b = c/d = e/f = 5/7 है, तो (3a + 5c + 11e)/(3b + 5d + 11f) = ?

- गुणांक ऊपर-नीचे एक जैसे (3, 5, 11) → उत्तर = **5/7**

**Q8.** a/b = c/d = e/f = 2/3 है, और व्यंजक में सब पद वर्ग (²) में हैं, गुणांक ऊपर-नीचे एक जैसे। उत्तर?

- बस (a/b)² लो = **4/9**

---

## 5. टाइप 4 – पड़ोसन मेथड (3x = 5y = 4z)

**नियम:** हर एक का मान = **बाकी सबके गुणांकों का गुणा** (अपना छोड़कर)।

**Q9.** 3x = 5y = 4z है, तो x : y : z = ?

- x = 5 × 4 = 20, y = 3 × 4 = 12, z = 3 × 5 = 15
- उत्तर: **20 : 12 : 15**

**Q10.** 2p = 3q = 4r = 5s है, तो p : q : r : s = ?

- p = 3×4×5 = 60, q = 2×4×5 = 40, r = 2×3×5 = 30, s = 2×3×4 = 24
- ÷ 2 → **30 : 20 : 15 : 12**

### भिन्न (fraction) वाला रूप

**नियम:** a/b : b/c : c/a को साधारण अनुपात बनाने के लिए → **अपना ऊपर वाला × बाकी दोनों के नीचे वाले**।
(भिन्न और ":" एक साथ उत्तर में नहीं चलते।)

**Q11.** a : b : c = 2 : 3 : 5 है, तो a/b : b/c : c/a = ?

- 2/3 : 3/5 : 5/2
- 2×5×2 = 20, 3×3×2 = 18, 5×3×5 = 75
- उत्तर: **20 : 18 : 75**

**Q12.** x : y : z = 4 : 5 : 6 है, तो x/y : y/z : z/x = ?

- 4/5 : 5/6 : 6/4
- 4×6×4 = 96, 5×5×4 = 100, 6×5×6 = 180
- ÷ 4 → **24 : 25 : 45**

### 1 सेकंड वाला शॉर्टकट

तीसरे को भूल जाओ, सिर्फ़ पहले दो का अनुपात निकालो और ऑप्शन में मिलाओ।

- 3x = 5y → x : y = 5 : 3 → जिस ऑप्शन में पहले दो पद 5 : 3 हों।
- p/q : q/r का अनुपात = (p × r) : (q × q)
  - Q12 में: x·z : y² = 4×6 : 25 = **24 : 25** → यही ऑप्शन ✔

## 6. टाइप 5 – कब्ज़ा मेथड (A:B और B:C दिया, A:B:C निकालो)

**नियम:** जहाँ खाली जगह है, वहाँ पड़ोसी (साथ वाला) संख्या का "कब्ज़ा" होता है, उससे पूरी पंक्ति गुणा करो।

```
A : B : C
2 : 3        → ×1 (C वाली पंक्ति का B)
    1 : 4    → ×3 (A वाली पंक्ति का B)
-----------
2 : 3 : 12
```

**Q13.** A : B = 4 : 5, B : C = 3 : 7 → A : B : C = ?

- 4×3 : 5×3 : 7×5 = **12 : 15 : 35**

**Q14.** A : B = 1 : 3, B : C = 2 : 5, C : D = 2 : 3 → A : B : C : D = ?

- **4 : 12 : 30 : 45**
- जाँच: 4:12 = 1:3 ✔, 12:30 = 2:5 ✔, 30:45 = 2:3 ✔

**Q15.** P : Q = 4 : 3, Q : R = 5 : 2 → P : Q : R = ?

- **20 : 15 : 6**

### ऑप्शन से जाँच (1 सेकंड)

पूरा मत बनाओ, सिर्फ़ एक जोड़ा (A:B या B:C) ऑप्शन में मिलाओ। दो ऑप्शन बचें तो दूसरा जोड़ा देखो।

## 7. टाइप 6 – गुणा मेथड (सिर्फ़ पहला और आखिरी पूछा हो)

**नियम:** सब अनुपातों को सीधा गुणा कर दो (बीच वाले B, C अपने-आप कट जाते हैं)।
A : D = (सारे पहले पद का गुणा) : (सारे दूसरे पद का गुणा)

**Q16.** A : B = 2 : 3, B : C = 4 : 5, C : D = 6 : 7 → A : D = ?

- (2×4×6) : (3×5×7) = 48 : 105 = **16 : 35**

**Q17.** A : B = 2 : 3, B : C = 5 : 7 → C : A = ?

- A : C = 10 : 21 → **C : A = 21 : 10** (क्रम उल्टा पूछा है)

**Q18.** A : B = 3 : 4, B : C = 8 : 9, C : D = 15 : 16 → A : D = ?

- (3×8×15) : (4×9×16) → काटकर **5 : 8**

**Q19.** A:B = 2:3, B:C = 4:5, C:D = 6:7, D:E = 10:9 → A : E = ?

- (2×4×6×10) : (3×5×7×9) = 480 : 945 = **32 : 63**

> **होमवर्क:** A:B = 1:2, B:C = 3:4, C:D = 5:6 → A : D = ?
> (उत्तर: 15 : 48 = 5 : 16)

## 8. टाइप 7 – जोड़ (Sum) वाले अनुपात

**Q20.** P : Q = 3 : 4, Q : R = 4 : 7 → (P+Q) : (Q+R) : (R+P) = ?

- P : Q : R = 3 : 4 : 7
- **7 : 11 : 10**

**Q21.** (a+b) : (b+c) : (c+a) = 15 : 14 : 11 और a + b + c = 40 है। 3a + b − 4c = ?

- तीनों जोड़ो: 2(a+b+c) = 40k → a+b+c = 20k = 40 → k = 2
- a+b = 30, b+c = 28, c+a = 22
- c = 40 − 30 = 10, a = 40 − 28 = 12, b = 40 − 22 = 18
- 3a + b − 4c = 36 + 18 − 40 = **14**

> **मान (value)** पूछा हो तो असली संख्या चाहिए; **अनुपात** पूछा हो तो दिया गया कुल मान बेकार डेटा है।

**Q22.** (a+b) : (b+c) : (c+a) = 7 : 6 : 5, a + b + c = 27। 1/a : 1/b : 1/c = ?

- a+b+c = 9k → c = 2k, a = 3k, b = 4k (27 वाला डेटा अनुपात के लिए बेकार)
- 1/3 : 1/4 : 1/2 → **4 : 3 : 6**

**Q23.** (a² + b²) : (b² + c²) : (c² + a²) = 34 : 61 : 45 (a, b, c धनात्मक)। (b − a) : (c − b) : (c − a) = ?

- जोड़ो: 2(a² + b² + c²) = 140 → a² + b² + c² = 70
- c² = 36, a² = 9, b² = 25 → a = 3, b = 5, c = 6
- **2 : 1 : 3**

## 9. टाइप 8 – कुल जोड़ (Sum Total) बराबर करने वाला मेथड

**मुख्य बात:** a/(b + c) जैसे हर अनुपात में **ऊपर + नीचे = a + b + c** (कुल) होता है, जो हर अनुपात में **समान** है।
तो हर अनुपात का (अंश + हर) बराबर कर दो (LCM से)।

**Q24.** a/(b + c) = 1/3 (यानी 3/9), c/(a + b) = 5/7 (यानी 10/14)। b/(a + c) = ?

- कुल: 3 + 9 = 12 और 10 + 14 = 24 → सबको 24 बनाओ
- a = 6, c = 10, b = 24 − 16 = 8
- b/(a + c) = 8/16 = **1/2**

**Q25.** p/(q + r) = 2/5, r/(p + q) = 6/7। q/(p + r) = ?

- कुल 7 और 13 → LCM 91
- p = 2 × 13 = 26, r = 6 × 7 = 42, q = 91 − 68 = 23
- q/(p + r) = **23/68**

**Q26.** (a+b+c)/d = 17/3, (a+c+d)/b = 3/1, (a+b+d)/c = 3/2। (b+c+d)/a = ?

- कुल: 20, 4, 5 → सबको 20 बनाओ
- d = 3, b = 1 × 5 = 5, c = 2 × 4 = 8, a = 20 − 16 = 4
- (b+c+d)/a = 16/4 = **4/1**

**Q27.** (x+y+w)/z = 7/3, (x+z+w)/y = 5/2, (x+y+z)/w = 11/4। (y+z+w)/x = ?

- कुल: 10, 7, 15 → LCM 210
- z = 3 × 21 = 63, y = 2 × 30 = 60, w = 4 × 14 = 56
- x = 210 − 179 = 31
- उत्तर: **179/31**

### 1 सेकंड वाला शॉर्टकट (ऑप्शन से)

1. **अंश + हर = कुलों का LCM** (या उसका गुणज/गुणनखंड)।
2. **ऊपर ज़्यादा अक्षर हों तो अंश बड़ा**, ऊपर एक ही अक्षर हो तो अंश छोटा।

- Q27: ऊपर तीन अक्षर → अंश बड़ा; 179 + 31 = 210 ✔
- Q25: ऊपर एक अक्षर → अंश छोटा; 23 + 68 = 91 ✔

## 10. याद रखने वाली बातें

- अनुपात हमेशा एक जैसी इकाई में।
- a/b = 3/2 का मतलब a = 3k, b = 2k; घात अलग हो तो उत्तर "ज्ञात नहीं"।
- (A+B)/(A−B) दिखे → योगांतरानुपात।
- 3x = 5y = 4z → पड़ोसन मेथड (बाकी सबका गुणा)।
- A:B, B:C → कब्ज़ा मेथड; सिर्फ़ पहला-आखिरी पूछा → सीधा गुणा।
- a/(b+c) वाले → कुल बराबर करो; ऑप्शन में अंश + हर = LCM जाँचो।
- पूरा हल करने से पहले ऑप्शन से एक जोड़ा मिलाकर देखो।
